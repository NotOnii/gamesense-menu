# gamesense-menu

A standalone DX9 recreation of the gamesense menu, rebuilt from static reverse engineering of the menu code. Menu only: no game code.

## Build

Needs Visual Studio (x64 tools). Run `build.bat` to build `gsmenu.exe`. All images are embedded in the exe.

## Layout

- `main.cpp`: window, D3D9 device, GDI font atlas, DPI handling
- `ui.h`: UI framework (menu, tabs, groupboxes, and all element classes)
- `menu_data.h`: the full menu tree, **generated** by `re/gen.js`
- `menu_rules.h`: visibility and enable rules, per-weapon configs, weapon Copy/Paste
- `assets_data.h`: embedded PNGs, generated by `re/embed.js` from `assets/`
- `re/`: the data pipeline and its outputs (see `re/README.txt`)
- `ref/`, `diff.js`: pixel regression check against a reference capture of the Misc tab

## Testing hooks

```
gsmenu.exe --capture out.bmp
node diff.js out.bmp ref/misc.bgra
```

- `GS_EVENTS="down:x,y;move:x,y;up:x,y;rdown:x,y;rup:x,y;key:vk;wheel:x,y,d,ctrl"` replays input before the capture.
- `GS_RESIZE=WxH` resizes the window.
